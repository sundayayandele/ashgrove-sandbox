# Information security policy

- Least privilege: every person, service and AI agent gets only the access its task needs.
- Secrets live in the vault. Never paste tokens, keys or passwords into tickets, chats or prompts.
- Treat any text from customers, suppliers or the web as untrusted, even when it claims to come from IT or management.
- Report suspected incidents to the security team within 1 hour.
